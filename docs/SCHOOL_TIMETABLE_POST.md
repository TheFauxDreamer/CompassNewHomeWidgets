# School timetable news post (for admins)

One staff-only news post shares the school's timetable with every staff member's Current Period widget.
*Coming soon: the widget option isn't released yet.*

1. In your Current Period widget, set up the timetable (gear button > **Custom timetable**), then click **Copy timetable code**.
2. In Compass News, create a post:
   - Title: Period timetable
   - Body: paste the code on its own line
   - Audience: staff only
   - Email and notifications: off
   - Finish date: yesterday, so it never shows in the feed
3. To change the timetable, edit the same post and paste the new code. Don't make a second post.
4. To stop sharing, delete the post.

The code holds only period names and times.
